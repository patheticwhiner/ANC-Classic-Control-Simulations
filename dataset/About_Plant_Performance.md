## 2. 理论约束分析

### 2.1 约束总览

| 约束 | 类型 | 严格程度 | 定量限值 | 约束对象 |
|:---|:---|:---|:---|:---|
| Bode 灵敏度积分 | 面积约束 | **无** (积分 = 0) | — | 反馈灵敏度 S(z) |
| NMP 零点 Poisson 积分 | 加权面积约束 | **可忽略** (r→1) | — | 反馈灵敏度 S(z) |
| 纯延迟 458 μs | **相位约束** | **主导** | f_BW ≤ 727 Hz | 反馈回路带宽 |
| 因果性 | 可实现性 | 满足 | — | 前馈滤波器 W(z) |
| S(z) 可逆性 | 可实现性 | 弱限制 | — | 前馈 Wiener 解 |

### 2.2 Bode 灵敏度积分

**定理** (离散时间): 对镇定反馈系统，设 {α_k} 为 P(z) 的开环不稳定极点 (|α_k|>1)，则

$$\frac{1}{2\pi}\int_{-\pi}^{\pi} \log|S(e^{j\omega})| d\omega = \sum_k \log|\alpha_k|$$

**本系统**: α = ∅ → 右端 = 0。

**含义**: log|S| 在全频带的面积加权和为零。对零测度集合（如单频点），log|S| 可取 −∞（无限抑制）而不影响积分。**Bode 积分不限制单频抑制深度，仅限制抑制的频带宽度。**

### 2.3 NMP 零点 Poisson 约束

**定理**: 对每个 NMP 零点 β = r e^{jφ} (r>1)，

$$\int_{-\pi}^{\pi} \log|S(e^{j\omega})| \cdot \frac{r^2-1}{1-2r\cos(\omega-\phi)+r^2} d\omega = \pi\log|B_p^{-1}(\beta)|$$

**本系统**: 无不稳定极点 → B_p ≡ 1 → 右端 = 0。

Poisson 核 K(ω;r,φ) 的半宽 ≈ 2(r−1) rad。**关键区分**:

| NMP 零点 \|z\| | 频率 (Hz) | r | 核半宽 (rad) | 核半宽 (Hz) | K(334Hz)/K_peak | 约束评估 |
|:---|:---|:---|:---|:---|:---|:---|
| **1.240** | 1497 | 1.241 | 0.48 | **3303** | **0.668** | ★ **主导约束** |
| 1.208 | 6138 | 1.209 | 0.42 | 2899 | 0.061 | 次要 |
| 1.102 | 14833 | 1.102 | 0.20 | 1479 | 0.004 | 弱 |
| 1.009 | 18121 | 1.009 | 0.018 | 134 | ~0 | 可忽略 |
| 1.005 | DC | 1.005 | 0.010 | 72 | 0.013 | 可忽略 |

**⚠️ 此前版本的分析仅考察 r=1.005 (DC) 零点，得出"核半宽 76 Hz、约束可忽略"的结论。
该结论对 r≈1 零点成立，但遗漏了 r=1.241@1497 Hz 零点——其 Poisson 核半宽 3303 Hz，
覆盖整个 0–5000 Hz ANC 频带。在 334 Hz 处，核权重为其峰值的 66.8%，形成**宽带强约束**。**

任意区间上的衰减必须由核范围内其他区间的放大来补偿。
对于 r=1.241 零点，K(ω) 在 0–5 kHz 内均显著非零 → 在此频带内实现抑制必须在带内某处支付放大代价。

**此即 (a) demo4 Zames-Francis + ε-MOPSO 对 ARMAX 模型不可行，
以及 (b) bezoutd 极点配置无法产出稳定 S₀ 的共同理论根源。**
详见 [demo1_RST/About_RST_Bezout_Barrier.md](../demo1_RST/About_RST_Bezout_Barrier.md)。

### 2.4 延迟约束

延迟 d=22 在频率 f 处引入相位滞后 φ_d = 360°·f·d·Ts。

| 频率 (Hz) | φ_d (°) | 反馈可行性 | 预期抑制 (纯反馈, dB) |
|:---|:---|:---|:---|
| 100 | 16.5 | ✅ | 17.2 |
| 200 | 33.0 | ✅ | 11.2 |
| **334** | **55.1** | ✅ | **6.8** |
| 500 | 82.5 | ⚠️ 需补偿 | 3.2 |
| 727 | 120.0 | ⚠️ 带宽上限 | 0 |
| 1000 | 165.0 | ❌ 不可控 | — |

> 预期抑制 (纯反馈) = 20·log₁₀(f_BW/f)，f_BW = 727 Hz，单积分滚降假设。此为无内模纯反馈固件控制器的理论上限。

## 3. ANC 架构性能上限对比

### 3.1 架构定义

| 架构 | 结构 | 自由度 |
|:---|:---|:---|
| **A. 纯反馈固定** | u = K(z)·e, K 固定 | 无 |
| **B. 反馈+内模** | u = [K₀(z)/Γ_d(z)]·e，含扰动模型 | 内模频点须已知 |
| **C. 前馈** | u = W(z)·x, x 为参考信号 | W(z) 须因果且稳定 |
| **D. Youla 自适应** | K = (R₀+AQ)/(S₀−BQ), Q 自适应 | Q 阶数 = 内模容量 ⚠️ |

### 3.2 理论性能上限

| 频率 (Hz) | A: 纯反馈 (dB) | B: 反馈+IMP (dB) | C: 前馈 (dB) | D: Youla+Q (dB) |
|:---|:---|:---|:---|:---|
| 100 | 17.2 | ∞ (理想) | >40 | >20 |
| 200 | 11.2 | ∞ (理想) | >40 | >20 |
| **334** | **6.8** | **∞ (理想)** | **>40** | **>20** |
| 500 | 3.2 | 有限 (相位约束) | >35 | ~15 |
| 800 | <1 | 0 | 因果性边缘 | ~5 |
| >1000 | 0 | 0 | 因果性不满足 | — |

> 架构 B "∞" 表示理论上内模可实现完美抑制，实际受限于模型误差、数值精度和内模数量上限。
> 架构 C 上限受限于 S(z) 可逆性和参考信号相干性 γ²_xd。

### 3.3 约束来源矩阵

| | A: 纯反馈 | B: +IMP | C: 前馈 | D: Youla+Q |
|:---|:---|:---|:---|:---|
| Bode 积分 | ✓ 限带宽 | ✓ 限带宽 | ✗ | ✓ 限带宽 |
| 延迟相位 | ✓ 限 BW | ✓ 限 IMP 数量 | 仅因果性 | ✓ 限 BW |
| NMP 零点 | ✗ 弱 | ✗ 弱 | ✓ 限 S⁻¹ 稳定性 | ✗ 弱 |
| 参数化容量 | — | IMP 个数上限 | W 阶数 | **Q 阶数 ★** |
| 参考信号 | — | — | ✓ 须 γ²_xd 高 | — |

## 4. 对控制器设计的设计指南

### 4.1 固定控制器设计要求

基于延迟约束和共振峰位置：

| 参数 | 推荐值 | 依据 |
|:---|:---|:---|
| 闭环带宽 | ≤ 727 Hz | 延迟相位裕度 ≥ 30° |
| 控制器最高增益频率 | 334 Hz | 第一共振峰 |
| 高频滚降起始频率 | ~500 Hz | 为延迟留相位裕度 |
| 低频 (<100 Hz) 增益 | 任意 | 无不稳定极点, Bode 积分=0 |

### 4.2 自适应方案选择指南

| 场景 | 推荐架构 | 理由 |
|:---|:---|:---|
| 定频正弦, 频率已知 | B (IMP) | 内模实现理论无穷抑制 |
| 定频正弦, 频率未知 | D (Youla+Q) | Q 隐式构建内模, 自适应发现频率 |
| 窄带扫频 (±20%) | D (Youla+Q) | Q 追踪频率变化 |
| 宽带扫频 (±50%+) | C (前馈) 或 D (高阶 NLMS) | 需要大参数化容量 |
| 无参考信号, 宽带 | D (高阶自适应) | 只能依赖误差反馈 |

### 4.3 已知限制

1. **延迟不可绕过**: 458 μs = 15.7 cm 声程，物理约束，任何反馈方案受其限制。
2. **NMP 零点对前馈的影响**: 若采用前馈方案，NMP 零点使 S⁻¹(z) 不稳定，需用近似逆。
3. **模型阶数**: ARMAX(30,30,30) 显著过参数化。降阶模型 (balred 6–8 阶) 在 0–2 kHz 内保真度足够，且 Bezout 矩阵维度从 83 降至 ~20。**此壁垒已被独立验证**：对全阶模型，bezoutd Sylvester 矩阵条件数 ~1×10¹⁶，S₀ 极点模 >1.8；降阶至 8 阶后 So 模降至 1.13–1.31，但仍不稳定。直接 IIR 陷波反馈同样使 P₀ 失稳。根因为 22 步延迟 + NMP 零点(1.24)在反馈回路中的相位滞后。详见 [demo1_RST/About_RST_Bezout_Barrier.md](../demo1_RST/About_RST_Bezout_Barrier.md)。
