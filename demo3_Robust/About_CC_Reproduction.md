## 1. 原版代码的四个核心缺陷

对照 2017 JVC 论文 Section 5–6，`Jafari_AdaptiveCC.m` 原版存在以下偏差：

### 缺陷 1：扰动频率单位错误（Hz → 应为 rad/s）

| | 论文 | 原版代码 |
|---|------|----------|
| 扰动频率 | ω = 70, 187 **rad/s** | f = 70, 187 **Hz** |
| 对应物理频率 | ≈ 11.1, 29.8 Hz | = 70, 187 Hz |
| 换算为 rad/s | 70, 187 rad/s | ≈ 440, 1175 rad/s |

**后果**：F(s) 滤波器 α=500，带宽覆盖 [0, 600] rad/s。代码中的扰动频率（440, 1175 rad/s）远超 F 的带宽，控制器在扰动频率处几乎无增益，自然无法抑制。同时 187 Hz 的 Nyquist 条件也成问题（fs=10⁴, Nyquist=5×10³ Hz，虽勉强成立但相位特性恶化）。

**修复**：
```matlab
% 原版（错误）：
f = [70, 187];  % 被当作 Hz 使用
d = d + A(k)*sin(2*pi*f(k)*t + phi(k));

% 修正版：
omega = [70, 187];  % rad/s，论文原值
d = d + A(k)*sin(omega(k)*t + phi(k));
```

### 缺陷 2：自适应滤波器阶数不足（N=6 → 应为 20）

| | 论文 | 原版代码 |
|---|------|----------|
| N（Λ 基函数个数） | 20 | 6 |

**论文依据**：Section 6 明确设定 N=20。理论要求 N ≥ 2·n_max（最大频率分量数 n_max=5），故 N≥10 为必要条件，N=20 提供足够冗余度。

**后果**：N=6 意味着 FIR 滤波器仅有 6 个自由度，不足以在多个频率点构造零点实现完全抑制。自适应律即使收敛，K(s,θ)=θᵀΛ(s) 也无法逼近最优的 G₀⁻¹。

### 缺陷 3：控制律结构错误（u = −F[θᵀφ] → 应为 u = −F[θᵀΛ[z]]）

这是**最隐蔽也最关键的结构性错误**。

**论文的正确信号流**（Eq. 6–8, 12）：

```
z(t) = y(t) − G₀(s)[u(t)]                           (辅佐信号)
φ(t) = G₀(s)F(s)Λ(s)[z(t)]                          (回归向量，用于参数估计)
u(t) = −F(s)[K(s,θ)[z(t)]] = −F(s)[θᵀΛ(s)[z(t)]]   (控制律)
```

关键点：**φ 和 Λ[z] 是两个不同的信号**。φ = G₀FΛ[z] 包含 G₀F 滤波——这是参数辨识所需的。但控制律只需要 θᵀΛ[z]（即 FIR 滤波后的 z），不应再乘 G₀F。

**原版代码的信号流**：

```
z(k) = y(k) − G₀[u(k−1)]                             (正确)
φ(k) = G₀FΛ(s)[z(k)]                                 (正确)
u(k) = −F[θᵀφ(k)] = −F[θᵀG₀FΛ[z]]                  (❌ 错误!)
```

原版代码直接用 `θᵀφ` = `θᵀG₀FΛ[z]` 作为控制信号输入，等效于在反馈回路中多串联了一个 G₀F。当 θ 收敛时，θᵀG₀FΛ ≈ I（辨识目标），于是 u ≈ −F[z]，退化为固定增益反馈，丧失了自适应控制器的频率选择性。

**修复**：在仿真循环中分离两类信号：
```matlab
for i = 1:Nparam
    % Λ_i[z_k] → 级联一阶节滤波 → lambda_vals(i)  ← 用于控制
    % Λ_i[z_k] → F → G₀ → phi_reg(i)               ← 用于参数辨识
end
% 参数更新：用 phi_reg
% 控制信号：用 lambda_vals
K_z_ctrl = theta.' * lambda_vals;           % θᵀΛ[z]，不含 G₀F！
u(k) = -F[K_z_ctrl];                        % 论文 Eq. 6–8
```

### 缺陷 4：Λ(s) 高阶 TF 直接离散化 → 数值崩溃

原版代码将 Λ_N(s) = λ²⁰/(s+λ)²⁰ 直接作为单个高阶传递函数，用 `c2d(..., 'tustin')` 离散化，然后用 `tfdata` 提取分子分母多项式系数。

**问题**：(s+500)²⁰ 展开后的系数跨 50+ 个数量级（常数项 = 500²⁰ ≈ 9.5×10⁵³）。Tustin 离散化后的 z 域多项式系数同样极端。在 IIR 滤波器差分方程中：

```matlab
y_out = (num_part − den_part) / den(1);
```

den(1) 受限于机器精度（double ≈ 10⁻¹⁶），与 10⁵³ 量级的系数相比，计算结果立即退化为 NaN。

**修复**：将 Λ_i(s) = [λ/(s+λ)]ᵏ 实现为 k 个一阶节的**级联**：
```matlab
% 一阶基单元
G1(s) = λ/(s+λ)  →  c2d(G1, Ts, 'tustin')  →  G1(z)

% Λ_i 的 i 级联实现
casc_out = z_k;
for stage = 1:order_i
    [casc_out, state_u(stage), state_y(stage)] = IIR_filter(numG1, denG1, casc_out, ...);
end
lambda_vals(i) = casc_out;  % Λ_i[z_k]
```

每个一阶节的系数保持在合理范围内（|num|, |den| ≈ 1），数值稳定。

## 2. 计算耗时分析

### 为什么修正版比原版慢得多？

原版（N=6, 单高阶 TF）每样本的 IIR 滤波运算量：

| 组件 | 滤波器数 | 每次 FIR 乘法数 | 总乘法/样本 |
|------|---------|----------------|------------|
| 系统 G | 1 | ~3×3 | ~9 |
| 观测 G₀ | 1 | ~3×3 | ~9 |
| 控制 F | 1 | ~4×4 | ~16 |
| Λ_i（最高 6 阶） | 6 | ~7×7 | ~294 |
| F（φ 链路） | 6 | ~4×4 | ~96 |
| G₀（φ 链路） | 6 | ~3×3 | ~54 |
| **合计** | | | **~478** |

修正版（N=20, 级联一阶节）每样本的 IIR 滤波运算量：

| 组件 | 滤波器数 | 每次 FIR 乘法数 | 总乘法/样本 |
|------|---------|----------------|------------|
| 系统 G | 1 | ~3×3 | ~9 |
| 观测 G₀ | 1 | ~3×3 | ~9 |
| 控制 F | 1 | ~4×4 | ~16 |
| Λ_i（级联，最高 20 节） | **Σ order_i = 210** | ~2×2 | ~840 |
| F（φ 链路） | 20 | ~4×4 | ~320 |
| G₀（φ 链路） | 20 | ~3×3 | ~180 |
| **合计** | | | **~1374** |

**运算量增长**：1374/478 ≈ **2.9×**，但主要为级联 Λ 滤波器所致（840 vs 294, ≈ 2.9×）。

实际耗时增长更大（约 **5–10×**），原因是：
1. **MATLAB 循环开销**：原版 6 次 `for` 循环，修正版 210 次级联 + 20 次外层 = 230 次循环迭代/样本，MATLAB 解释执行开销大。
2. **3D 数组索引**：`phi_Lambda_u(i,stage,:)` 的 `reshape` 操作增加了内存访问开销。
3. **历史缓冲区更长**：N=20 导致 `hist_len` 从 ~10 增长到 ~30，每次 `IIR_filter` 中 `FIR()` 需要处理更长的历史向量。

### 优化建议

**方案 A：预计算 Λ 级联的状态空间实现（推荐，>10× 加速）**

将 k 个一阶节的级联合并为单个状态空间模型，利用 MATLAB 的 `series` 或手动构建：

```matlab
% 替代每次循环中的级联 IIR 调用
% 预计算每个 Λ_i 的等效状态空间模型
[A_i, B_i, C_i, D_i] = cascaded_ss(numG1, denG1, order_i);
% 仿真时用矩阵乘法替代循环
```

**方案 B：降低 N 到 12**

若扰动频率较少（2 个），N=12 可满足 N ≥ 2·n_max = 10 的要求。210 次级联 → 78 次，运算量减半。

**方案 C：降采样**

若扰动仅到 30 Hz，fs=1000 即可满足 Nyquist。fs 从 10⁴ 降到 10³ → 样本数减 10×。

**方案 D：MEX/C 加速**

将 IIR_filter 的循环用 C MEX 实现，消除 MATLAB 解释开销。

## 3. 参数调优经验

### 控制能量问题的根源

G₀(s) = 0.5(s−0.2)/(s²+s+1.25) 在扰动频率处的增益：

| 频率 | \|G₀\| | 所需 \|G₀\|⁻¹ | F 提供的增益 |
|------|--------|--------------|-------------|
| 70 rad/s (11.1 Hz) | −43 dB (0.007) | +43 dB (×140) | +37 dB |
| 187 rad/s (29.8 Hz) | −51 dB (0.003) | +51 dB (×374) | +44 dB |

G₀ 是一个低增益被控对象（RHP 零点 + 二阶谐振滚降），在扰动频率处增益极低。要产生足以抵消扰动的反相声波，控制信号必须达到扰动幅值的 140–374 倍。这是**物理必然**，不是算法缺陷。

### κ₀ 与 θ_max 的调参 trade-off

对 κ₀ ∈ {0.05, 0.10, 0.20, 0.50} 和 θ_max ∈ {3, 5, 10, 20} 进行了 16 组合扫描（T=2s, fs=10⁴, N=20，结果见下页）。

**κ₀（F 滤波器的增益标量）**：

- κ₀↑ → F 增益↑ → 控制器权威↑ → 抑制效果↑ → 控制能量↑ → 鲁棒裕度↓
- κ₀ 是抑制-vs-鲁棒的**主控旋钮**

**θ_max（参数投影界）**：

- 实际收敛 ‖θ‖ ≈ 2.5（与 κ₀ 弱相关，除非 κ₀ 过小导致 θ 撞界）
- θ_max ≤ 5 时 θ 被投影约束，反过来限制了闭环增益
- θ_max 的**唯一作用**是保证鲁棒稳定性证明成立——论文定理要求 κ₀·θ̄_M·‖F̄G₀Δₘ‖₁ < 1

### 参数扫描结果

| κ₀ | θ_max | 抑制 (dB) | u_RMS | ‖θ‖ | 鲁棒 LHS | 安全? |
|------|--------|-----------|-------|------|----------|-------|
| 0.05 | 3 | −1.3 | 26 | 3.00 | 0.04 | ✅ |
| 0.05 | 5 | −2.2 | 44 | 5.00 | 0.06 | ✅ |
| 0.05 | 10 | −3.6 | 69 | 9.56 | 0.12 | ✅ |
| 0.10 | 3 | −2.5 | 48 | 3.00 | 0.07 | ✅ |
| 0.10 | 5 | −4.7 | 80 | 5.00 | 0.12 | ✅ |
| 0.10 | 10 | −8.8 | 126 | 8.73 | 0.25 | ✅ |
| **0.20** | **10** | **−16.9** | **168** | **5.62** | **0.50** | ✅ |
| 0.20 | 20 | −16.9 | 168 | 5.62 | 1.00 | ⚠️ |
| **0.50** | **5** | **−25.8** | **187** | **2.46** | **0.62** | ✅ |
| 0.50 | 10 | −25.8 | 187 | 2.46 | 1.25 | ❌ |
| 0.50 | 20 | −25.8 | 187 | 2.46 | 2.50 | ❌ |

*鲁棒 LHS = κ₀ · θ_max · ‖F̄G₀Δₘ‖∞，其中 ‖F̄G₀Δₘ‖∞ ≈ 0.25。LHS < 1 表示满足定理 3 的鲁棒稳定性条件。*

### 推荐配置

| 场景 | κ₀ | θ_max | 抑制 | u_RMS | 鲁棒 LHS |
|------|-----|--------|------|-------|----------|
| 🥇 **性能优先** | 0.50 | 5 | −25.8 dB | 187 | 0.62 ✅ |
| 🥈 **均衡** | 0.20 | 10 | −16.9 dB | 168 | 0.50 ✅ |
| 🥉 **低控制能量** | 0.10 | 10 | −8.8 dB | 126 | 0.25 ✅ |
