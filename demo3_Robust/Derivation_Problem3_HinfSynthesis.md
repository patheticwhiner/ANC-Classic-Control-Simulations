## 题目

> **已知**：
>
> **(1)** 被控对象（Bai 1997 耳机器件模型，连续时间）：
>
> $$P(s) = 0.3921 \cdot \frac{(s + 3.0841)(s - 1.0320)(s + 0.4387)(s - 0.0034)}{(s - 0.6612 \pm j0.3483)(s + 0.4426 \pm j0.3324)}$$
>
> 注：含 2 个 RHP 零点 ($s = 1.0320$ 和 $s = 0.0034$) 和 2 个 RHP 极点——系统**开环不稳定**且**非最小相位**。
>
> **(2)** 控制目标：
> - 低频扰动抑制（ANC 的典型需求：抑制 $< 1$ kHz 的噪声）
> - 高频鲁棒稳定性（对未建模高频动态的裕度）
> - 限制控制能量（防止扬声器饱和）
>
> **求**：
> (a) 三权重函数 $W_1(s), W_2(s), W_3(s)$ 的设计
> (b) 广义被控对象 $P_{aug}(s)$ 的构造
> (c) 用 `hinfsyn` 综合控制器，解释 $\gamma$ 的含义
> (d) 验证设计的性能与鲁棒性

## 解

### 第1步 · 审题

对比前两题，本题的特点是：

| 特征 | 题1 & 题2（自适应） | 题3（H∞ 混合灵敏度） |
|:---|:---|:---|
| 控制器类型 | 自适应（参数在线更新） | **固定**（离线一次设计） |
| 扰动先验知识 | 频率未知但个数有界 | **不依赖频率信息**——用权重函数刻画全频带需求 |
| 建模不确定性处理 | 投影 + 小增益验证 | **显式加权**（$W_3 \cdot T$） |
| 理论依赖 | Part A | Part B |
| 数学问题类型 | 在线系统辨识 + 自适应 | **离线凸优化**（两个 Riccati 方程） |

**核心思路**：将所有性能需求编码为三个频域权重函数 $W_1, W_2, W_3$，将它们和被控对象打包为广义被控对象 $P_{aug}$，然后调用 `hinfsyn`（内部实现 DGKF 的 γ-迭代 [Theory_Foundations.md §B.3–B.4](Theory_Foundations.md)）求解最优控制器。

---

### 第2步 · 三权重函数的设计

> 引用 [Theory_Foundations.md 定义 B.5](Theory_Foundations.md)：混合灵敏度问题为
> $$\left\| \begin{bmatrix} W_1 S \\ W_2 K S \\ W_3 T \end{bmatrix} \right\|_\infty < 1$$

#### 2.1 $W_1(s)$ — 性能权重

**作用**：$S = (1+PK)^{-1}$ 是从扰动到输出的传递函数。ANC 要求在低频段（噪声能量集中的频带）有强抑制，即 $|S(j\omega)|$ 很小。

**设计策略**：$W_1(s)$ 取**低通**形式，低频高增益 → 迫使 $S$ 在低频段增益反比于 $W_1$。

本题用二阶逆低通形式：

$$
W_1(s) = \frac{s^2 + 7969s + 8.542 \times 10^6}{2.37s^2 + 2500s + 1.027 \times 10^7} \tag{3.1}
$$

- DC 增益：$|W_1(0)| = 8.542 \times 10^6 / 1.027 \times 10^7 \approx 0.83$ → 要求 $|S(0)| < 1/0.83 \approx 1.2$（0 dB）
- 在 100 Hz 处：$|W_1(j200\pi)| \approx 50$ → 要求 $|S| < 1/50$ ≈ −34 dB 的扰动抑制
- 高频 → 0：不对高频灵敏度施加约束

直观：「你在 100 Hz 以下要认真干活（抑制噪声），在高频管不管都行。」

#### 2.2 $W_2(s)$ — 控制能量权重

取为小常数（而非频变滤波器）：

$$W_2(s) = 10^{-3} \tag{3.2}$$

物理含义：控制器在任何频率处的输出 $|K(j\omega)S(j\omega)|$ 不能超过 $10^3$。此处选的极小值意味着**几乎不限制控制能量**——在 $K$ 本身稳定的约束下让其自由发挥。

#### 2.3 $W_3(s)$ — 鲁棒性权重

**作用**：$T = PK(1+PK)^{-1}$ 是互补灵敏度函数。高频未建模动态要求 $|T(j\omega)|$ 在高频段快速滚降。

**设计策略**：$W_3(s)$ 取**高通**形式（或其倒数 $W_3^{-1}$ 为低通，方便 Bode 图上显示为边界）。

本题：

$$W_3(s) = \frac{s + 3266}{0.6554s + 2592} \tag{3.3}$$

- 低频（$s \to 0$）：$W_3(0) = 3266/2592 \approx 1.26$ → 不对低频 $T$ 施加额外约束（$T(0) \approx 1$ 是跟踪所需）
- 高频（$s \to \infty$）：$W_3(\infty) = 1/0.6554 \approx 1.53$ → 要求 $|T(j\omega)| < 1/1.53 \approx -3.7$ dB，即高频增益被抑制

**三权重的汇总**：

| 权重 | 形状 | 约束的信号 | 物理意义 |
|:---|:---|:---|:---|
| $W_1$ | 低通 | $S$（灵敏度） | 低频扰动抑制强 |
| $W_2$ | 常数（极小） | $KS$（控制灵敏度） | 几乎不限制控制力 |
| $W_3$ | 高通 | $T$（互补灵敏度） | 高频鲁棒稳定 |

---

### 第3步 · 广义被控对象的构造

`augw(G, W1, W2, W3)` 自动完成以下连线 [Theory_Foundations.md 定义 B.2](Theory_Foundations.md)：

```
         ┌──────────┐
    w ───┤          ├─── z₁ = W₁·S·w
         │   P_aug  ├─── z₂ = W₂·KS·w
    u ───┤          ├─── z₃ = W₃·T·w
         │          ├─── y  = w + G·u
         └──────────┘
```

广义被控对象的输入为 $[w; u]$（扰动 + 控制），输出为 $[z_1, z_2, z_3; y]$（加权性能 + 测量）。`hinfsyn` 接手后自动处理闭环 $u = K(s)y$ 并寻找最优 $K(s)$。

```matlab
P_aug = augw(P_tf, W1, 1e-3, W3);
nmeas = 1;  % y 的维度
ncon  = 1;  % u 的维度
[K_hinf, ~, gamma] = hinfsyn(P_aug, nmeas, ncon);
```

---

### 第4步 · $\gamma$ 的含义与判读

`hinfsyn` 返回的 $\gamma$ 是闭环从 $w$ 到 $z$ 的 H∞ 范数：

$$\gamma = \| \mathcal{F}_\ell(P_{aug}, K) \|_\infty$$

[Theory_Foundations.md 表 B.1](Theory_Foundations.md) 的判读在此处完全适用：

| $\gamma$ | 含义 | 应对 |
|:---|:---|:---|
| $< 1$ | ✅ 设计成功—所有三项目标满足 | 可收紧权重获取更强性能 |
| $\approx 1$ | 刚好满足 | 可接受 |
| $> 1$ | ❌ 失败—存在至少一个频率点违反约束 | 放宽 $W_1$ 的带宽/增益；降低 $W_3$ 的高频要求；增加 $W_2$ 允许更大控制力 |

本题代码的典型结果 $\gamma < 1$，表示 $|W_1S| < 1$、$|W_2KS| < 1$、$|W_3T| < 1$ 在所有频率同时成立。

---

### 第5步 · 验证

#### 5.1 频域验证

合成控制器后，画 Bode 图比较：

- $|S(j\omega)|$ vs. $|W_1^{-1}(j\omega)|$：若前者始终在后者的下方 → 性能目标满足
- $|T(j\omega)|$ vs. $|W_3^{-1}(j\omega)|$：若前者始终在后者的下方 → 鲁棒目标满足

这本质就是检查 $\gamma < 1$ 的频域等价条件 [Theory_Foundations.md 式 (B.5)](Theory_Foundations.md)。

#### 5.2 时域验证

构造多正弦扰动（模拟 ANC 中的多频噪声），对比开环响应 vs. 闭环响应，计算 RMS 抑制比。

# 附录

## 附录A · MATLAB 实操完整示例

> 来源：`Derivation_Problem3_Appendix_HinfTutorial.md`

以下是从零到一的 `augw` + `hinfsyn` 实操流程，与上文的理论推导互补：

```matlab
%% 1. 定义被控对象和权重函数
s = tf('s');
G = 1 / (s^2 + 0.2*s + 1);              % 二阶被控对象

M = 100; wb = 1; A = 1e-4;              % 性能权重参数
W1 = (s/M + wb) / (s + wb*A);           % 低通 — 低频扰动抑制
W3 = tf([1/1.5 10], [1 1000]);          % 高通 — 高频鲁棒性
W2 = [];                                 % 不限控制能量

%% 2. 构造广义对象 + 综合
P = augw(G, W1, W2, W3);
[K, CL, gamma] = hinfsyn(P, 1, 1);      % SISO: NMEAS=1, NCON=1

%% 3. 验证
L = G * K;
S = feedback(1, L);  T = feedback(L, 1);
bodemag(S, 1/W1);    % S < 1/W1 → 性能目标满足
bodemag(T, 1/W3);    % T < 1/W3 → 鲁棒目标满足
```

**$\gamma$ 值与权重设计的迭代关系**：

| $\gamma$ | 操作 |
|:---|:---|
| $< 1$ | 设计成功。可收紧 $W_1$ 获取更强性能 |
| $\approx 1$ | 可接受 |
| $> 1$ | 放宽 $W_1$ 带宽/增益，或降低 $W_3$ 高频要求 |

`hinfsyn` 内部通过 DGKF 的 γ-迭代（[Theory_Foundations.md §B.4](Theory_Foundations.md)）自动二分搜索最小的 $\gamma$。
