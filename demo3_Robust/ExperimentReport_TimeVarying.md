# 实验报告：时变频率扰动下固定 vs 自适应 ANC

> **实验日期**：2026-06-08
> **模型**：ARMAX(30,30,30,22), $f_s=48000$ Hz
> **$F(z)$**：9 NMP 零点反射 + 1 阶 LPF

---

## 1. 实验设计

| 条件 | 设置 |
|:---|:---|
| 扰动类型 | 单频正弦 + 白噪声 $\sigma=0.02$ |
| 频率变化 | **300 Hz → 370 Hz 线性扫频**（4.7 Hz/s） |
| 固定控制器 | FIR $N=120$，设计频率 $f_0 = 334.6$ Hz（$G_0$ 共振峰） |
| 自适应控制器 | RLS $N=64$, $P(0)=0.1I$, $\lambda=0.9999$, $\theta_{\max}=200$ |
| 仿真时长 | 15 s |

## 3. 算法迭代过程

### 3.1 第一代：RLS 稳态调参 — 崩溃

参数 $P(0)=0.1$, $\lambda=0.9999$。在 314–342 Hz 给出平坦 22.7 dB，但 344 Hz 后崩溃至 −20 dB。

**根因**：RLS 的 $P$ 矩阵随时间单调衰减，Kalman 增益趋向零——算法对频率变化"睡着了"。

### 3.2 第二代：RLS 跟踪调参 — 持续发散

尝试 $P(0)=5\sim20$, $\lambda=0.997\sim0.9985$，加入 $P_{\min}$ 下界。结果始终为负抑制（−0.9 到 −10 dB）。

**根因**：RLS 在非平稳环境中有两个互相矛盾的需求——需要小 $P$ 来保持稳态精度，需要大 $P$ 来跟踪变化。遗忘因子 $\lambda$ 的调谐窗口极窄，且 $P$ 的特征值下界（逐元素截断）不能真正替代特征值分解。

### 3.3 第三代：NLMS — 成功

$$\theta(k+1) = \theta(k) + \mu \cdot \frac{e(k) \cdot \phi(k)}{\phi^T(k)\phi(k) + \varepsilon}, \qquad \mu = 0.05$$

NLMS 的固定步长 $\mu$ 消除了 RLS 的核心矛盾——学习率不随时间衰减。

## 5. 分析

**固定控制器**：在 $f_0$ 附近峰值 25.4 dB，但带宽有限——$\pm 30$ Hz 偏离后掉到 6 dB。这是 FIR 滤波器 $Q$ 因子的直接后果。

**NLMS 自适应**：全频段（326–366 Hz）给出平坦的 21.4–22.6 dB 抑制。关键特性：
- **频率无关性**：40 Hz 扫频范围内抑制波动仅 1.2 dB
- **无崩溃**：RLS 的 $P$ 衰减问题在 NLMS 中不存在——$\mu=0.05$ 固定步长提供恒定跟踪带宽
- **代价**：在固定控制器的设计频率处，NLMS 的 22.5 dB 略低于固定的峰值 25.4 dB——这是固定步长导致的稳态误调（steady-state misadjustment），约为 $10\log_{10}(\mu/2) \approx -16$ dB 的本底

## 6. 结论

| 场景 | 方案 | 性能 |
|:---|:---|:---|
| 频率已知且固定 | 固定 $F(z)+K(z)$ | 峰值 25 dB @ $f_0$ |
| 频率固定但未知 | RLS 自适应（稳态调参）| 全频 23 dB |
| **频率时变** | **NLMS 自适应** | **全频 22 dB，无崩溃** |

**工程法则**：RLS 用于稳态辨识（高精度），NLMS 用于非平稳跟踪（高鲁棒性）。在 ANC 中，若扰动频率可能时变，**用 NLMS 替代 RLS**——固定步长的恒定跟踪带宽消除了 $P$ 矩阵衰减导致的"睡眠"问题，代价仅为约 1–3 dB 的稳态精度损失。
