## Phase 1：被控对象性能上限分析

**目标**：回答"这个系统理论上最多能抑制多少噪声？"

### 1.1 已有分析（可直接跑）

```matlab
results = analyze_armax_model('armax_30303022');
```

输出：能观标准型、互质性、强可镇定、零极点位置、阶跃/脉冲/Bode 图

### 1.2 频域特性深度分析（需新增脚本）

新建 `dataset/analyze_plant_performance.m`，输出：

| 分析项 | 方法 | 回答的问题 |
|:---|:---|:---|
| 频率响应 | `freqz(B,A,8192)` | 共振峰位置、增益、带宽 |
| NMP 零点精确定位 | 分析 |z|>1 的根 | 确认是辨识 artifact 还是物理零点 |
| Bode 灵敏度积分 | ∫ log\|S\| dω = π·Σlog\|α_k\| | 水床效应——低频抑制必导致高频放大 |
| 延迟的带宽约束 | d=22 样本 @ 48kHz → 458μs | 理论可达带宽 ≈ 1/delay ≈ 2.2kHz |
| 可实现抑制上限 | 结合 NMP 零点 + 延迟 | 宽带噪声下最优可达抑制 (dB) |
| 共振峰敏感度 | 扰动 A/B 多项式系数 ±5% | 控制器设计对模型误差的敏感度 |

### 1.3 输出

- `dataset/output/plant_analysis.mat` — 结构化分析结果
- 频域响应图（含共振峰标注）
- 性能上限总结表：各频段的理论最优抑制

## Phase 2：统一测试基准

### 2.1 测试信号（三组）

| 测试 | 信号 | 验证目标 |
|:---|:---|:---|
| T1 固定频率 | 第一共振峰 f₀ Hz 正弦 | 稳态抑制能力 |
| T2 线性扫频 | f₀±20% 线性扫描 | 固定控制器的频域鲁棒性 |
| T3 宽带噪声 | 100–1000 Hz 带限白噪声 | 综合性能（最接近真实场景） |

三组测试统一参数：`Tsim=10s`, `rng(42)`, 信号功率归一化到 0.8。

### 2.2 评估指标

| 指标 | 定义 |
|:---|:---|
| 稳态抑制 (dB) | 20·log₁₀(RMS(y_open) / RMS(y_closed))，取后 80% 稳态段 |
| 收敛时间 (s) | 自适应控制器从启动到抑制 > 50% 稳态值的时间 |
| 控制能量 | max\|u\| 和 RMS(u)，用于评估饱和风险 |
| 鲁棒性 | 扫频测试中抑制的方差（方差小 = 鲁棒好） |
