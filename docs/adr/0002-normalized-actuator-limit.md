# 统一归一化执行器约束

## 状态

已接受

## 决策

Cylinder 1 dm 测试基准统一使用归一化执行器模型，硬限幅为 `u ∈ [-5, 5]`。调参阶段要求候选控制器的未限幅峰值不超过 4，最终评价阶段保留未限幅控制需求与硬限幅后的实际控制量；出现任何限幅时，不将该控制器认定为成功设计。

## 背景

当前低阶辨识模型的输入输出已做归一化，仓库没有可用于换算真实电压或声压的执行器标定。旧 Demo 脚本已有 `|u| <= 5` 的约定，但未形成统一的批量验收规则。

## 影响

该约束使控制量比较可复现，并避免大控制动作通过限幅掩盖模型或控制器问题。由于缺少物理标定，结果中的执行器约束只能解释为归一化仿真约束，不能直接宣称满足真实硬件额定值。
