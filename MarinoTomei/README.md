# Marino2011 自适应非线性控制器

这个MATLAB程序实现了基于Marino(2011)理论的一个自适应非线性控制系统仿真。该控制器能够在存在未知参数和外部扰动的情况下实现稳定的跟踪控制。

## 系统描述

该项目模拟了一个二阶非线性系统，系统动态方程为：

```
dx₁/dt = x₂ + a₁x₁ + (1/β)u + w₁
dx₂/dt = (1/β)b₂u
y = x₁
```

其中：
- a₁, b₂, β 为未知参数
- w₁ 为外部扰动
- u 为控制输入
- y 为系统输出

## 控制目标

控制系统输出 y 跟踪给定的参考信号 y_r = -w₂，其中 w₂ 是一个已知的时变信号。

## 主要特点

- **自适应参数估计**：在线估计未知系统参数
- **鲁棒性**：能够处理结构化的外部扰动
- **状态滤波器**：使用赫尔维茨（Hurwitz）矩阵设计的状态滤波器
- **投影算法**：使用投影算子确保参数估计在给定范围内

## 参数说明

### 系统参数
- `a₁`, `b₂`, `β`：未知系统参数（在仿真中设为已知用于生成状态）
- `ω₁`, `ω₂`, `ω₃`：扰动信号的频率

### 控制器参数
- `k`：控制增益
- `g`：参数更新增益
- `d`：矩阵D的参数 [d₂, d₃, d₄, d₅]

## 使用方法

1. 打开 `test.m` 文件
2. 根据需要调整参数
3. 运行脚本以执行仿真
4. 查看生成的输出跟踪性能和参数估计图表

## 函数说明

- `system_dynamics`：描述整个系统动态的主函数
- `get_w1`, `get_w2`：生成扰动信号
- `projection`：参数估计的投影算子

## 仿真结果

仿真将产生两个图形：
1. **输出跟踪性能**：显示系统输出和参考信号，以及跟踪误差随时间的变化
2. **参数估计**：显示参数估计值随时间的收敛情况

## 特殊场景设置

该仿真中包含了几个特殊场景用于测试控制器的鲁棒性：

- `t < 50秒`：扰动w₁包含两个频率分量
- `t ≥ 50秒`：扰动w₁仅包含一个频率分量
- `t < 100秒`：参考信号为正弦波
- `t ≥ 100秒`：参考信号变为零

## 参数调整建议

- 增加 `k` 可以提高跟踪性能但可能导致控制信号过大
- 增加 `g` 可以加快参数估计收敛速度但可能引起震荡
- 矩阵 `D` 的特征值会影响状态滤波器性能，应确保其为赫尔维茨矩阵

## 参考文献

Marino, R., & Tomei, P. (2011). "An adaptive learning control for nonlinear systems with unknown control directions."
