# RST 极点配置壁垒：ARMAX(30,30,30,22) @48kHz 固定反馈控制器设计

> **状态**: 已验证的结构性壁垒  
> **关联**: [dataset/About_Plant_Performance.md](../dataset/About_Plant_Performance.md) §2.3 (Poisson 约束修正)

---

## 1. 问题

为 Youla 参数化设计中心控制器 R₀/S₀ 时，bezoutd 方程对所有设计参数组合均产出内部不稳定的控制器（S₀ 零点 >1），且直接 IIR 陷波反馈同样使闭环特征多项式失稳。本文档从理论和数值两个层面给出根因分析。

---

## 2. 理论根因：Poisson 积分约束（r=1.241 零点）

### 2.1 约束定理

对 NMP 零点 β = r e^{jφ} (r>1)，灵敏度函数 S(z) 必须满足：

$$\int_{-\pi}^{\pi} \log|S(e^{j\omega})| \cdot \underbrace{\frac{r^2-1}{1-2r\cos(\omega-\phi)+r^2}}_{\text{Poisson 核 } K(\omega)} d\omega = 0 \quad (\text{无不稳定极点})$$

### 2.2 关键零点：r=1.241 @1500 Hz

被控对象有 5 个 NMP 零点。**此前文档仅定量考察了 r≈1 零点（核半宽 ~70 Hz），遗漏了主约束零点**：

| 零点 |z| | 频率 | r | 核半宽 | K(334Hz)/K_peak | 约束评估 |
|:---|:---|:---|:---|:---|:---|
| **1.240** | 1497 Hz | 1.241 | **3303 Hz** | **0.668** | **主导 ★** |
| 1.208 | 6138 Hz | 1.209 | 2899 Hz | 0.061 | 次要 |
| 1.102 | 14833 Hz | 1.102 | 1479 Hz | 0.004 | 弱 |
| 1.009 | 18121 Hz | 1.009 | 134 Hz | ~0 | 可忽略 |
| 1.005 | DC | 1.005 | 72 Hz | 0.013 | 可忽略 |

r=1.241 零点的 Poisson 核**半宽 3303 Hz**，覆盖整个 ANC 频带 (0–5000 Hz)。
在 334 Hz 处，核权重仍为峰值的 **66.8%**——这构成**宽带强约束**，而非窄带弱约束。

### 2.3 约束的物理含义

Poisson 积分要求 log|S| 的核加权均值为零。由于核在 0–5 kHz 全频带显著非零：

> **任何频带的抑制必须在核覆盖范围内以放大为代价**。334 Hz 处的抑制代价
> 无法分散到极远处（如 Nyquist 频率）——必须由 0–5 kHz 带内某处的放大来支付。

对于窄带单频抑制 (Δf ≈ 10 Hz @334 Hz)，Poisson 约束本身允许很深抑制
（所需宽带放大 ≈ A·K(334)/K_avg·(Δf/3303) ≈ A×0.0027，即 20 dB 抑制仅需 0.05 dB 宽带放大）。
**Poisson 约束不直接限制窄带深度**——但它迫使 S(z) 在零点附近保持特定解析结构，
限制了可实现 S(z) 的形状空间。

### 2.4 与延迟的协同效应

延迟 d=22 引入相位滞后 φ_d(334 Hz) = 360°·334·22/48000 = 55.1°。
NMP 零点 β 要求 S(β)=1（插值约束）。配合延迟相位滞后，反馈回路在 334 Hz 附近
的相位裕度被挤压。固定反馈控制器要在此频率提供高增益，必须引入超前补偿——
但 r=1.241 零点的宽带 Poisson 核意味着超前补偿引入的放大不能局限在无害频带，
必须在 0–5 kHz 带内某处"偿还"。

**三者协同形成设计壁垒**：
1. 近单位圆极点 (max|p|=0.996 @334 Hz) → 被控对象在目标频率增益高 (+2.5 dB)
2. r=1.241 NMP 零点 @1500 Hz → 宽带 Poisson 约束限制灵敏度函数形状
3. 22 步延迟 @48 kHz → 相位滞后 55°，进一步压缩设计空间

## 3. 数值表现：bezoutd 的失效

### 3.1 全阶模型 (30 阶)

| 指标 | 值 |
|:---|:---|
| Sylvester 矩阵维度 | 84×84 |
| 条件数 | 1.9×10¹⁶ |
| S₀(K2) 零点最大模 | **1.80** |
| 仿真 (纯音 100+200 Hz) | k≈1155 发散, u→Inf |
| 仿真 (纯音 + 0.1 randn) | k≈1155 发散 |

Sylvester 矩阵的 84 个方程中，约 45 个为"额外约束"（要求 A·HS·S₁ + B·HR·R₁
的高阶项严格对消）。22 步延迟在 B 中产生 22 个前导零 → Toeplitz 结构中
约 22 行近似零行 → 矩阵近乎秩亏。

Poisson 约束限制了合法 S(z) 的形状空间。bezoutd 试图在数值病态的
Sylvester 矩阵上求解一个已被 Poisson 约束压缩到近乎空集的方程——
结果迫使 S₁ 零点越过单位圆以"补偿"数值误差与物理约束的冲突。

### 3.2 降阶模型 (balred 8 阶)

为缩小 Sylvester 矩阵，对延迟分离后的 B_star/A 做 balred 至 8 阶。

| 降阶阶数 | Sylvester | S₀ max\|root\| | 仿真结果 |
|:---|:---|:---|:---|
| 8 (默认 PF) | 40×40 | 1.31 | k≈2833 发散 |
| 8 (PF 扫参) | 40×40 | 1.13–2.05 | 最优 S₀=1.129 时 P₀ 已不稳定 |
| 8 (直接 IIR 陷波) | — | — | P₀ 不稳定 (max\|root\|=1.004) |
| 全阶 R₀=0, S₀=1 | — | — | 稳定, 但 0 dB 抑制 |

降阶将 S₀ 从 1.80 改善至 1.13–1.31，证明**模型阶数是因素之一但非全部**。
即使完全绕过 bezoutd（直接 IIR 陷波），P₀ 仍失稳——根因不在数值方法，
在于 Poisson 约束 + 延迟 + 近单位圆极点三者叠加后，**固定反馈增益的可行空间为空**。

### 3.3 Landau 参考代码验证

| 条件 | max\|u\| | supp | 说明 |
|:---|:---|:---|:---|
| K2 + 纯音 100+200 Hz (无噪声) | 5.2e6 | +23.6 dB | 边界稳定，但控制量巨大 |
| K2 + 纯音 + 0.1 randn | 3.1e7 | -125 dB | 噪声激发 S₀ 不稳定模 |
| K2 + FFT 窄带指标 | — | ~110 dB@单频点 | 残留输出，非当前模型 |

Landau 的 YKNANC_05 在**理想纯音、精确匹配陷波频率**下边界稳定——
S₀ 不稳定模未被充分激发。任何宽带噪声（包括 0.1 量级）均触发发散。
这解释了其嵌入输出的 110 dB 数字——在严格受控的理想条件下测得，不可推广至一般场景。

## 4. 修正后的架构评估

| 架构 | 之前估计 | 修正 | 理由 |
|:---|:---|:---|:---|
| A. 纯反馈固定 | ≤6.8 dB | **≈0 dB** | 任何显著增益 → P₀ 失稳 |
| B. 反馈+IMP (反馈路径) | ∞ (理想) | **≈0 dB** | IMP 在反馈路径同样受 Poisson 约束 |
| B*. 反馈+IMP (前馈路径) | — | **∞ (理论)** | 需参考信号。内模不在反馈回路内 |
| C. 前馈 (有参考) | >40 dB | >40 dB | 需参考麦克风 |
| **D. Youla+Q** | >20 dB | **≈1 dB (nQ=20)** | 固定 R₀/S₀ 不可设计；Q 受 NMP 限制 |

### 4.1 IMP 反馈路径实验 (2026-06-13)

在 S₀ 中嵌入阻尼谐振器 `[1, −2r·cos(ω₀), r²]`，扫描 (r, k):

```
r ∈ {0.90, 0.95, 0.98, 0.99, 0.995, 0.998, 0.999}
k ∈ {1e-4, 5e-4, 1e-3, 5e-3, 1e-2, 5e-2, 1e-1, 5e-1, 1}

稳定组合仅限: k ≤ 0.01 (r=0.9), k ≤ 0.001 (r=0.999)
所有稳定组合下: |S_ye|@334Hz ≈ 0.98–1.0 (0 dB)
k 稍增 → P₀ 立即失稳 (max|root|>1)
```

**结论**: IMP 在反馈路径中无法绕过 Poisson 约束。谐振器提供的额外增益
同样受 NMP 零点 + 延迟限制——增益稍大即推动闭环极点出单位圆。
IMP 的优势**仅在前馈路径**中体现（内模在回路外，不受反馈 Poisson 约束）。

### 4.2 根本限制

Poisson 积分 (r=1.241@1500Hz, 核半宽 3303 Hz) + 22 步延迟 (φ=55°@334Hz)
+ 近单位圆极点 (0.996@334Hz) → 反馈回路在 334 Hz 处可施加的增益存在硬上限，
该上限不足以产生有意义的窄带抑制。**不是数值问题，不是模型阶数问题，
不是设计方法问题——是物理特性决定的反馈结构极限。**

## 5. 可行路径

1. **架构 C — 前馈 ANC**: 需参考麦克风。前馈路径不受反馈 Poisson 约束。
2. **自适应陷波滤波器 (ANF)**: 从误差信号中提取频率，用 LMS 陷波器直接生成反噪——非反馈结构
3. **直接 Q 参数化 + 高阶 FIR**: nQ=20 仅 1.1dB，nQ 继续增大？(计算代价)
4. **H∞/H2 频域设计**: 显式加权 Poisson 核，可能找到比极点配置更优的解
